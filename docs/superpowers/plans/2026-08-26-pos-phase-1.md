# RotiRopi POS Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Build complete Android-first React Native POS UI mock using screenshots and `DESIGN.md`.

**Architecture:** Expo SDK 57 with Expo Router. One React Context reducer owns mock state; shared tokenized components render adaptive compact, tablet, and short-landscape layouts. Backend, persistence, and native printing remain absent.

**Tech Stack:** React Native, TypeScript, Expo SDK 57, Expo Router, React Context/useReducer, Jest.

**Spec:** `docs/superpowers/specs/2026-08-26-pos-phase-1-design.md`

## Global Constraints

- Screenshots override `DESIGN.md`; legacy UI never supplies visual direction.
- Keep Android `minSdk` at API 24 unless a documented hard dependency prevents it.
- Optimize for old/low-end Android: no blur, heavy animation, large shadow, large image, or broad context subscriptions in repeated rows.
- Minimum touch target `48dp`; minimum font size `12sp`.
- One canonical shared component per UI function.
- No backend/API, OAuth, persistence, offline queue, or printing integration.
- All visible copy uses Indonesian.
